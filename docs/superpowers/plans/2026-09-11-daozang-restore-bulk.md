## 之后：人工智能校定（先想清楚，不在 9/15 范围）

人工校定页（左原图 / 右朱砂、确认|不通过+备注）已经是入口。大模型应**接在这条人审后面**，不要代替几何复原、也不要自动覆盖原图或复原文件。

推荐分层，由便宜到贵：

1. **启发式（已有）**  
   备注关键词 → `keep | retint | reknockout | geometry | other`。无密钥也能跑。

2. **VLM 抽检，不跑 4 万**  
   把原图与复原图（或缩略图）送进视觉模型，只问：构图是否同一张、是否明显增删笔画、抠底是否残纸。  
   输出与校定表相同的 JSON。先对「不通过」和随机 1–2% 抽检，而不是全量。  
   提示词要点：只判几何与抠底，禁止重绘，禁止把复原当成原文。

3. **OCR 只用于带字的图**  
   对照原扫描与墨线里的字是否同文。无字符图不要上 OCR。

4. **Agent**  
   工具：`list_fail_calibrations`、`open_pair`、`classify`、`queue_retint`。  
   人仍点最终确认。Agent 可以开重抠/重染任务，**不得写原扫描目录**。

Skill 形态：一条「道藏插图质检」skill，写明输入（原 URL + 复原 URL + 可选备注）、禁止项、JSON schema。接现有 `restore_calibrations` 表即可。

模型选型（后选，不锁死）：先用已配置的 `DZ_LLM_*`；若要看图，再加带 vision 的兼容接口。不必为校定新开框架。
